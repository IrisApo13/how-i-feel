Waving Character — Figma’s animation, plus a CSS idle on top

The wave is Figma’s, untouched. Breathe / blink / sway are CSS layered onto the parts Figma isn’t driving. This is the combination I’d actually ship: Figma for the motion that’s hard to hand-write, CSS for the ambient stuff.

Layer the idle on top

The wave keeps running underneath. Nothing fights, because they drive different elements.

Why Figma’s is smoother

It sets the pivot with a translate → rotate → translate sandwich baked into every keyframe, instead of relying on transform-origin:

transform: translateX(374.177px) translateY(244.619px)
           translate(63.632px, 87.585px)   /* to the pivot */
           rotate(-0.262rad)               /* turn */
           translate(-63.632px, -87.585px) /* and back */

Same result, but every frame is a plain matrix the compositor can interpolate, with no layout-box resolution per frame. It also means the pivot is exact — Figma knew where your shoulder was; I was estimating it from a bounding box.

The one rule when combining them

Never apply transform-box: fill-box to an element Figma is animating. Its keyframes contain absolute coordinates that assume the default system, so fill-box teleports the part. In the CSS above, #arm is deliberately excluded.
